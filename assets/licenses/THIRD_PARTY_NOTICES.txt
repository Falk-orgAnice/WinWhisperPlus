WinWhisperPlus local text optimization notices
==============================================

This release bundles the following components for optional local text
optimization. They are used only on the user's computer and receive text only
through the loopback interface (127.0.0.1).

llama.cpp
---------
Project: https://github.com/ggml-org/llama.cpp
License: MIT License
Source revision: v0.6.0 (recorded by scripts/build-release.ps1)

Qwen3-4B / Qwen_Qwen3-4B-Q4_K_M.gguf
--------------------------------------
Original model: https://huggingface.co/Qwen/Qwen3-4B
GGUF quantization: https://huggingface.co/bartowski/Qwen_Qwen3-4B-GGUF
License: Apache License 2.0

The release build records the SHA-256 hash of the exact GGUF file in
textoptimizer/models/text-model.sha256. WinWhisperPlus verifies this hash
before it starts the local model server.

whisper.cpp 1.9.4 and Whisper / Silero VAD
---------------------------------------
Projects: https://github.com/ggml-org/whisper.cpp
          https://github.com/snakers4/silero-vad
Licenses: MIT. Models are downloaded from revision-pinned upstream repositories
listed in assets/model-catalog.json and checked against SHA-256 before use.
Local modification to whisper.cpp 1.9.4: CLI/server JSON exporters use the
library's VAD-aware token timestamp accessors instead of raw token_data times.
The reproducible source patch is scripts/patch-whisper-timestamps.py.

FFmpeg / imageio-ffmpeg 0.6.0
---------------------------
Projects: https://ffmpeg.org / https://github.com/imageio/imageio-ffmpeg
imageio-ffmpeg wrapper: BSD-2-Clause.
The packaged Windows binary is taken from the pinned imageio-ffmpeg wheel.
Its exact licensing/configuration is included in ffmpeg/LICENSE-FFmpeg.txt
(generated using ffmpeg -L) and ffmpeg/BUILD-FFmpeg.txt (ffmpeg -version).
The pinned Windows wheel contains FFmpeg 7.1 essentials (www.gyan.dev),
configured with --enable-gpl --enable-version3: GPL-3.0-or-later.
Build recipes and corresponding sources: https://www.gyan.dev/ffmpeg/builds/
Wrapper build information: https://github.com/imageio/imageio-ffmpeg/tree/v0.6.0
FFmpeg source: https://ffmpeg.org/download.html
