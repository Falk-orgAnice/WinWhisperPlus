WinWhisperPlus local text optimization notices
==============================================

This release uses the following components for optional local text
optimization. They are used only on the user's computer and receive text only
through the loopback interface (127.0.0.1).

llama.cpp
---------
Project: https://github.com/ggml-org/llama.cpp
License: MIT License
Source revision: v0.6.0 (recorded by scripts/build-release.ps1)

Qwen3-4B / Qwen_Qwen3-4B-Q4_K_M.gguf
--------------------------------------
Original model: https://huggingface.co/Qwen/Qwen3-4B
GGUF quantization: https://huggingface.co/bartowski/Qwen_Qwen3-4B-GGUF
License: Apache License 2.0

Model weights are downloaded to the current user's profile, not bundled.
The selected model revision, source URL and SHA-256 are pinned in
assets/model-catalog.json and checked before use.

whisper.cpp 1.9.4 and Whisper / Silero VAD
---------------------------------------
Projects: https://github.com/ggml-org/whisper.cpp
          https://github.com/snakers4/silero-vad
Licenses: MIT. Models are downloaded from revision-pinned upstream repositories
listed in assets/model-catalog.json and checked against SHA-256 before use.
Local modification to whisper.cpp 1.9.4: CLI/server JSON exporters use the
library's VAD-aware token timestamp accessors instead of raw token_data times.
The reproducible source patch is scripts/patch-whisper-timestamps.py.

---------------------------
Projects: https://ffmpeg.org / https://github.com/imageio/imageio-ffmpeg
imageio-ffmpeg wrapper: BSD-2-Clause.

Portable runtime deployment
---------------------------
The package includes Microsoft Visual C++ CRT and OpenMP redistributable DLLs
from the build machine's licensed Visual Studio VC/Redist/MSVC directory.
These Microsoft components remain subject to their applicable Microsoft
software license terms. They are deployed application-locally; the application
does not run a system-wide Visual C++ Redistributable installer.

Application-local Vulkan Loader
-------------------------------
Project: https://github.com/KhronosGroup/Vulkan-Loader
Source tag: v1.4.350, built for x64 with matching Vulkan-Headers v1.4.350.
License: Apache-2.0; cJSON is MIT-licensed.
The loader, LICENSE-Vulkan-Loader.txt and LICENSE-cJSON.txt are included beside
the GPU executables. CPU-only runtimes do not include or require the loader.
No graphics driver is bundled or installed.

Verified HTTPS downloads
------------------------
certifi: https://github.com/certifi/python-certifi
Mozilla CA root certificates; MPL-2.0 (license in licenses/certifi/LICENSE).
truststore: https://github.com/sethmlarson/truststore
Native platform certificate validation; MIT (license in licenses/truststore/LICENSE).
The CA bundle is used in memory, without installing certificates into Windows.
